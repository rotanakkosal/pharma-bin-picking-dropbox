What to upload to get grasp points
The server returns one suction pick point per bottle. It only works when you give it both images below, named as a pair.
Per scene, upload 2 files
1 Color photo (RGB) Required
.png / .jpg 8 bit 3 channels
A normal top down color picture of the bin. This is what the model sees to find each bottle.
2 Depth map Unlocks pick point
.png 16 bit 1 channel millimeters
Distance to every pixel, saved straight from the L515 depth stream. Working range about 250 to 1500 mm.
No depth means no pick point. An RGB only upload still works, but you get bottle outlines only and the central grasp dot is skipped.
Name the pair the same
The server matches RGB to depth by filename, not by folder. Give a photo and its depth the same base name.
Option A: split folders
my_capture/
├─ RGB/
│   ├─ 000000.png
│   └─ 000001.png
└─ Depth/
    ├─ 000000.png   ← same name
    └─ 000001.png
Option B: one folder, suffix
my_capture/
├─ IMG_001.png        (rgb)
├─ IMG_001_depth.png  (depth)
├─ IMG_002.png
└─ IMG_002_depth.png
Exact data types
FileFormatBit depthChannelsPixel value means
RGB PNG / JPG 8 bit 3 (R,G,B) Color
Depth PNG 16 bit 1 (grayscale) Distance in mm
The server reads the actual image content, not the filename. A depth map saved as 8 bit or 3 channel will be treated as a normal photo and ignored for picking. Camera intrinsics default to the L515. Add notes in the optional Metadata JSON box if needed.
What comes back
An overlay PNG per scene: each bottle outlined, with one colored dot at its suction pick point.
